Exercício de React do **Serratec (2021)**: um formulário de endereço que **se preenche sozinho** a partir do CEP.

## Como funciona

1. O usuário digita o **CEP**
2. A aplicação consulta a API pública do [ViaCEP](https://viacep.com.br/)
3. Os campos de **rua, bairro, cidade e estado** são preenchidos automaticamente

## Destaques técnicos

- Requisição HTTP com **Axios**
- Formulário controlado com `useState`
- Componentes `Formulario` e `Card`

## Como executar

```bash
npm install
npm start
```

A aplicação abre em `http://localhost:3000`.
